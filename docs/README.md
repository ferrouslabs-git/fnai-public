# Test and watch your own AI

Your AI runs on your own computers. Functional AI keeps the test questions, the scoring, the prompts and a record of what your
AI did.

**Start here:** [quickstart.md](quickstart.md): a scored test of your own code in five minutes (Python and TypeScript).

|---|---|

| [prompts-for-your-own-code.md](prompts-for-your-own-code.md) | keep prompts in Functional AI, fetch the live version, roll back without redeploying |
| [tracing.md](tracing.md) | record each call, model call and tool call |

| [space-keys.md](space-keys.md) | one key for servers and CI, with only the permissions you tick |
